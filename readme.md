# koishi-plugin-anime-convention-lizard-vincentzyu-fork
**anime-convention-lizard-vincentzyu-fork** 是一款针对漫展查询与订阅的 Koishi 插件。`漫展` 对接 **无差别同人站 (www.allcpp.cn)**，支持城市或主题关键词；`漫展B` 对接 **B站会员购**，支持地区活动查询与订阅。

## ✨ 特性

- 🔍 **多维查询**：支持按城市名或漫展主题关键词进行搜索。
- 📅 **订阅系统**：订阅感兴趣的关键词，一键获取所有关注城市的漫展动态。
- 🖼️ **精美渲染**：支持通过 Puppeteer 将查询结果渲染为精美图片（可选）。
- 🔤 **四档字体**：支持内置 npm 文楷、Release 下载文楷等宽版、服务端自定义字体或浏览器系统字体。
- 📺 **双数据源**：B站会员购支持漫展、展览、演出与本地生活活动范围。

## 📦 安装

在 Koishi webui的`插件市场`中搜索插件名`anime-convention-lizard-vincentzyu-fork` 并安装。

或者 Koishi webui的`依赖管理`中搜索npm包名`koishi-plugin-anime-convention-lizard-vincentzyu-fork` 并安装。

或者使用 npm/yarn：

```bash
npm install koishi-plugin-anime-convention-lizard-vincentzyu-fork
yarn add koishi-plugin-anime-convention-lizard-vincentzyu-fork
```

### 🛠️ 前置依赖
- **必须依赖**：`database` (用于存储订阅信息)
- **可选依赖**：`puppeteer` (用于图片渲染功能)
  - 推荐安装：`koishi-plugin-puppeteer` 或 `@shangxueink/koishi-plugin-puppeteer-without-canvas`

## ⚙️ 配置说明

### 🔗 数据源连接
`漫展` 会直接请求 allcpp.cn，`漫展B` 会直接请求 B站会员购。插件不再启动本地 HTTP 代理，也无需填写 API 地址、端口或请求模式。

### 📺 B站会员购设置
`漫展B` 默认查询范围可在控制台设置为：漫展、展览、演出、本地生活、全部或自定义。自定义范围可选择请求频道与保留的活动体裁；`按区县展开` 可提高北京、上海等大城市的覆盖率，但会增加请求数。

### 🖼️ 图片渲染设置
图片查询与图片详情依赖 Puppeteer 服务。启用对应指令后，可在控制台设置封面展示方式、深色主题、字体、PNG/JPEG/WebP 格式与截图质量；需要减小图片体积时，优先使用 JPEG 或 WebP 并降低截图质量。B站图片查询为保证稳定性最多展示最早开始的前 10 项，完整结果请使用文本查询。

### 📚 接口文档
- [Allcpp 直连接口与字段说明](doc/api/allcpp.md)
- [B站会员购接口、范围与已知限制](doc/api/bili.md)

### 🔤 字体设置
图片字体在控制台的 `fontMode` 选择，默认 `npm-lxgw`，影响「漫展」与「漫展B」的所有图片查询。

| 模式 | 行为 |
| :--- | :--- |
| `npm-lxgw` | 使用随插件安装的霞鹜文楷普通版；不发起网络请求，并仅嵌入当前图片所需的字体分片。 |
| `release-lxgw` | 首次图片查询从 Gitee、GitHub 依次下载霞鹜文楷等宽版到 Koishi 根目录 `data/fonts/LXGWWenKaiMono-Regular.ttf`；与 `60s` 等使用同一约定的插件共享缓存。 |
| `custom-path` | 读取下方 `customFontPath` 填写的 Koishi 服务端绝对路径，支持 `.ttf`、`.otf`、`.woff`、`.woff2`。 |
| `system-default` | 不读取字体文件，使用 Chromium 的系统字体栈。 |

Release 下载失败、字体文件校验失败、路径为空或无效时，图片查询会明确报错，不会自动切换字体模式；请修复配置或手动选择其他模式。

两个实验性补字开关位于字体路径下方：

| 配置项 | 默认值 | 行为 |
| :--- | :--- | :--- |
| `allowEmojiFontFallback` | 开启 | 仅在所选字体缺少 emoji 时，使用系统 emoji 字体补字。 |
| `allowSystemFontFallback` | 关闭 | 所选字体缺少普通字符时，使用系统默认字体补字；关闭时会直接拒绝出图并报告缺失字符。 |

图片主体不会自动切换到其他字体模式。普通失败始终写入控制台并回复简要修复建议；开启 `verboseConsoleLog` 或 `verboseSessionLog` 后，分别获得详细控制台诊断或会话诊断。

## 📖 使用方法

### 🔍 漫展查询
| 指令 | 说明 | 示例 |
| :--- | :--- | :--- |
| `漫展 查询 <关键词>` | 查询指定城市或主题的漫展 | `漫展 查询 南京` |
| `漫展 一键查询` | 查询所有已订阅关键词的漫展 | `漫展 一键查询` |
| `漫展 图片查询 <关键词>` | 以图片形式展示查询结果 | `漫展 图片查询 东方` |
| `漫展 一键图片查询` | 以图片形式展示所有订阅结果 | `漫展 一键图片查询` |

### 📌 订阅管理
| 指令 | 说明 | 示例 |
| :--- | :--- | :--- |
| `漫展 订阅 <关键词>` | 订阅指定关键词 | `漫展 订阅 上海` |
| `漫展 取消订阅 <关键词>` | 取消订阅指定关键词 | `漫展 取消订阅 上海` |
| `漫展 取消订阅` | 清空所有订阅 | `漫展 取消订阅` |
| `漫展 订阅列表` | 查看当前订阅的关键词 | `漫展 订阅列表` |

### 📺 漫展B：B站会员购
| 指令 | 说明 | 示例 |
| :--- | :--- | :--- |
| `漫展B 查询 <地区>` | 查询一个地区的会员购活动 | `漫展B 查询 北京` |
| `漫展B 查询 <地区> --scope <范围>` | 临时覆盖查询范围 | `漫展B 查询 上海 --scope 演出` |
| `漫展B 查询 <地区> --fanout` | 按区县展开查询 | `漫展B 查询 南京 --fanout` |
| `漫展B 图片查询 <地区>` | 图片形式展示最早开始的前 10 项 | `漫展B 图片查询 北京` |
| `漫展B 一键查询` | 查询已订阅地区 | `漫展B 一键查询` |
| `漫展B 订阅 <地区>` | 订阅一个地区 | `漫展B 订阅 南京` |
| `漫展B 取消订阅 [地区]` | 取消一个或全部地区订阅 | `漫展B 取消订阅 南京` |
| `漫展B 订阅列表` | 查看地区订阅 | `漫展B 订阅列表` |

可选范围：`漫展`、`展览`、`演出`、`本地生活`、`全部`、`自定义`。B站会员购只支持地区查询；作品或主题关键词请使用 `漫展 查询 <关键词>`。

### 📺 B站范围与查询建议
| 范围 | 查询内容 | 使用建议 |
| :--- | :--- | :--- |
| `漫展` | 漫展、Only同人展、IP展览和其他展览 | 默认选项，适合找漫展与同人活动。 |
| `展览` | B站展览频道 | 不限制体裁，适合查看全部展览。 |
| `演出` | 演出频道 | 演唱会、音乐会、话剧等。 |
| `本地生活` | 本地生活频道 | 快闪、主题餐厅等活动。 |
| `全部` | 所有已知频道 | 结果最多，适合不确定类别时使用。 |
| `自定义` | 控制台选择的频道与体裁 | 面向管理员的高级筛选。 |

`漫展B 查询 <地区> --fanout` 会额外查询市辖区、合并重复项目，适合北京、上海等大城市；它会增加请求次数。会员购单个地区频道最多返回 20 项，插件会按开始时间排序、按项目 ID 去重，并依控制台的最大结果数截断。B站图片查询最多渲染前 10 项，避免长列表与大封面导致 Chromium 资源耗尽。
